# Список людей (RHBZ)

Kivy-приложение: главный экран с кнопками, человек = **ФИО** + **звание**.

## Возможности

- **Добавить человека** — форма: ФИО, звание
- **Просмотр всего списка** — отдельное окно со всеми записями
- **Удалить человека** — выбор из списка и подтверждение
- **Рабочая директория** — папка для `people.json` (кнопка «Обзор» или ввод пути)

## Установка и запуск

```bash
cd RHBZ
pip install -r requirements.txt
python people_expense_gui.py
```

## Тесты

```bash
python test_storage.py
```

Конфиг: `RHBZ/data/config.json`. Список по умолчанию: `RHBZ/data/people.json`.
