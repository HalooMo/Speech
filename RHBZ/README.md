# Список людей (RHBZ)

Kivy-приложение: главный экран с кнопками, человек = **ФИО** + **звание**.

## Возможности

- **Рабочая директория** — обязательна; программа читает и пишет только в ней (`people.json`)
- **Список людей** — расход по причинам (наряд, отпуск, командировка, 40 РЦПС, больничный, госпиталь, прочие)
- **Работать** — сформировать 4 документа в папке `{рабочая_директория}/{ДД.ММ.ГГГГ}/`
- В окне «Список людей» — **Вернуть в общий список** (снять причину расхода)
- **Добавить / удалить** человека (ФИО + звание)

## Установка и запуск

```bash
cd RHBZ
pip install -r requirements.txt
python people_expense_gui.py
```

## Тесты

```bash
python test_storage.py
```

Конфиг: `RHBZ/data/config.json`. Список по умолчанию: `RHBZ/data/people.json`.

```bash
python -c "import storage; print(storage.import_from_ls_docx(replace=True))"
```
