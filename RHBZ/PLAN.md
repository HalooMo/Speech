# План: генерация документов из people.json

## Источник данных
- `people.json` в **рабочей директории**
- Поля: `fio`, `rank`, `status` (пусто = работает)
- Причины: наряд, отпуск, командировка, 40 РЦПС, больничный, госпиталь, прочие причины

## Шаблоны (только чтение) — `Pattern/`
| Шаблон | Что менять |
|--------|------------|
| `Строевая записка 02.06.2026.xlsx` | **Строка 1125** на Лист1 (R16) и блок на Лист2 (R9) |
| `Строевая записка 19.05.2026 1125 Ц(РХБЗ).xlsx` | **Одна строка** 1125: Лист1 R9, Лист2 R9 |
| `Строевая записка 19.05.docx` | Табл.0: счётчики R3; Табл.1: ФИО по причинам (строки 1–17) |
| `ШДС СО 30 чел (ОРФОШ).doc` | **6 строк** группы РХБЗ (должности 13–18): ФИО из списка |

## Выход
- Папка: `{рабочая_директория}/{ДД.ММ.ГГГГ}/`
- Имена с **текущей датой** создания
- Кнопка **«Работать»** на главном экране → генерация 4 файлов

## Этапы реализации
1. `export_docs.py` — разбор шаблонов, подстановка, копирование
2. Сопоставление `status` → строки/столбцы строевой
3. Word COM для `.doc` (ШДС)
4. Интеграция в `people_expense_gui.py` → `on_work`
5. `test_export_docs.py` — проверка без GUI

## Счётчики (docx табл.0, xlsx строка 1125)
- Пары столбцов в/с + г/п: наряд, ком-ка, отпуск, выезд, госпиталь, больничный
- В/с = число людей с причиной; г/п = 0 (пока не ведётся)
